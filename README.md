# SQL Insight

## Project Overview

SQL Insight is a learning and portfolio project designed to explore SQL Server operations, application-level logging, and database monitoring through a dashboard.

The project is inspired by practical experience working with SQL Server databases, investigating inconsistent records, correcting data, writing SQL queries, and supporting business applications. It aims to turn those experiences into a small application that makes database-related activity easier to understand and investigate.

## Project Goals

SQL Insight is being developed to:

- Record and review database-related operations performed through the application.
- Present operational information and trends through a dashboard.
- Explore diagnostic findings that could help identify potential data-quality or operational issues.
- Practise building a backend API, working with a relational database, and developing a frontend.
- Learn how to test, document, and maintain a software project using Git and GitHub.
- Prepare the application for a future deployment using Azure SQL Database.

## Technology Stack

The planned technology stack includes:

- **Backend:** C# and ASP.NET Core Web API
- **Database access:** Entity Framework Core
- **Database:** SQL Server, initially running locally
- **Frontend:** React and TypeScript
- **Future cloud integration:** Azure SQL Database and relevant database-monitoring features

The stack and features will evolve as development progresses.

## Application Logging vs. Database Monitoring

An important design goal is to keep two concepts separate:

- **Application-level operation logging:** Records activity that passes through the SQL Insight application, such as an operation initiated through an API endpoint.
- **Database-level monitoring:** Uses database-side capabilities to investigate database activity, performance, auditing, and query behaviour.

Application logs alone cannot capture every query executed directly against SQL Server or activity generated by other applications. Database-level monitoring will be explored separately as the project develops.

## Development Approach

SQL Insight is being built incrementally as a hands-on learning project. Development includes creating the database context and data models, connecting the API to SQL Server, implementing operation logging, building dashboard features, adding tests, and exploring cloud integration.

Each significant change is intended to be tested and recorded in Git with a meaningful commit message. The repository will document the project's progress and technical decisions as features are implemented.
